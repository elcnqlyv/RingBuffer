# Ring Buffer

A simple ring buffer implementation written in C.

I created this project to understand how circular buffers work and to practice working with structures and pointers.

The buffer stores up to 5 integer values.

## Features

* Add values to the buffer
* Remove values from the buffer
* Display the current contents
* Detect when the buffer is full or empty

## What I practiced

* Structures
* Pointers
* Functions
* Circular indexing
* Modulo operator

## Build

```bash
gcc ringbuffer-main.c -o ringbuffer
./ringbuffer
```
